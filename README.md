## The entry (147 characters)

> I asked my AI agent to water the plants while I was away. It opened 47 tabs about photosynthesis, billed me for a cloud, and the cactus still died.

## How to run

`main.py` (Python 3, standard library only) writes the line to
`entry.txt` in the output directory:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

The program is deterministic: no time, no randomness, no network. It
writes the exact same bytes on every run, with no trailing newline,
so the file holds exactly the 147-character line inside the
competition's 1–200 character gate.
